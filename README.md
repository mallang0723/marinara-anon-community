# 익명 커뮤니티 v2.3.50

v2.3.50: ‘본문 상황 참고’에 모든 댓글·답글도 상황 보충 의견으로 포함. 세계 주민·웹소설·드라마 모두 적용. 게시판을 읽는 설정 없이 상황·아이디어로 참고하며, 상충하는 의견이나 추측을 모두 사실로 확정하지 않도록 안내.

v2.3.49: 관점 탭 아래 ‘탭 테마’에서 세계 주민·웹소설·드라마 테마 각각 선택. 설정의 ‘현재 탭 지침’에서 게시판 이름·규칙 작성, ‘현재 탭의 생성 지침’에서 생성 프롬프트 수정. 이름·익명 이름·고정닉·규칙·생성 프롬프트·뉘앙스는 방·관점별 분리. 기존 공통 이름·규칙·수정 프롬프트·뉘앙스는 세계 주민에서만 사용하며 시청자에 상속하지 않음. 드라마는 영상 화면·표정·행동·대사 감상으로 작성하고 소설식 서술·문체 평가는 제외. 자료에 없는 촬영·음악·배우 정보 생성 금지 지침 추가.

v2.3.48: 상단 ‘세계 주민 / 시청자’ 탭 추가. 시청자 탭에서 웹소설 독자·드라마 시청자 선택. 관점별 목록·저장 목록·공지·이전 글/댓글 참고·RP 소재 전송 분리. 관점 선택은 방별 저장, 다른 관점에서 체크한 RP 소재는 해당 탭으로 돌아올 때 복귀. 관점 기록이 없는 예전 글은 업데이트 직전 방별/전체 관점 설정을 기준으로 분류. 기존 RP 본문·채팅 요약·일반 로어북·LTM 참고 선택은 공통 유지.

v2.3.47: ‘테마 말투 따르기’ 사용 시 레딧풍·4ch풍에 영미권 게시글의 가벼운 한국어 번역투 반영. 추가 번역 요청 없음.

Marinara에서 현재 채팅방을 참고해 익명 커뮤니티 게시글과 댓글을 생성하는 클라이언트 확장입니다. 원본 v2.3.1의 테마를 복원하고, 경량화·RP 연동·기록 저장 개선을 더한 수정판입니다.

## 설치

이 저장소에는 ZIP이 아닌 압축을 푼 소스가 들어 있습니다.

1. GitHub의 **Code → Download ZIP**으로 소스를 받아 압축을 풉니다.
2. `manifest.json`이 있는 폴더에서 Python 3으로 다음 명령을 실행합니다.

```sh
python scripts/package.py
```

3. 생성된 `dist/Anon-Community-v2.3.46-Lite.personal-extension.zip`을 Marinara의 개인/외부 확장 가져오기에서 선택합니다.
4. 전체 페이지 접근 권한을 검토하고 해당 파일의 해시를 승인한 뒤 확장을 활성화합니다. 가져오기·코드 변경 후에는 호스트의 승인이 필요할 수 있습니다.
5. 화면의 **커뮤니티** 버튼으로 열고, 설정에서 테마와 글 생성에 사용할 모델 연결을 선택합니다.

같은 확장을 중복 활성화하지 마세요. 기존 기록이 있다면 업데이트 전에 확장 설정에서 전체 백업을 받아 두세요. 다른 항목으로 새로 등록되어 기록이 보이지 않을 때는 이전 항목에서 받은 백업을 새 항목에 복원할 수 있습니다.

## 주요 기능

- 채팅방마다 게시판과 기록을 구분합니다. 공지, 추천·비추천, 직접 글쓰기, 댓글·답글, AI 댓글·답글, 북마크와 백업·복원을 지원합니다.
- 최근 글과 댓글 반응을 참고해 후속 화제를 만들며, 목록은 생성 순서로 표시합니다.
- 관점은 세계 주민, 웹소설 독자, 드라마 시청자, 직접 정하기로 나뉩니다. 전체 또는 방별로 지정할 수 있습니다.
- 글·댓글·답글에서 랜덤닉 또는 직접 설정한 닉네임을 선택합니다. 작성 닉네임과 부서·업계, 선택 모드는 방별로 유지됩니다.
- RP 시간 연동을 켜면 본문의 날짜·시간을 사용합니다. 끄면 시간 확인 없이 생성하고 실제 작성 시각을 사용합니다.
- 채팅 요약·로어북·캐릭터·페르소나·LTM 참고를 각각 켜거나 끌 수 있습니다. 이 선택은 모든 방의 공통 설정이며 현재 방의 자료를 읽습니다.
- 자료 준비·모델 응답 대기·변환 및 저장 시간, 전송 입력 글자 수를 표시합니다. 내부 모델 추론 시간을 별도로 측정하지는 않습니다.

## RP 소재 전달

게시글의 더보기 또는 RP 소재 탭에서 여러 글을 선택할 수 있습니다.

- **원문 넣기**: 제목·본문·모든 댓글·답글을 전달합니다.
- **본문 상황 참고**: 제목·본문의 상황을 참고하며 댓글·답글은 제외합니다.
- **세계 주민**: 원문을 작중 게시판 자료로 취급하며, 상황 방식은 게시판과 무관한 RP 상황으로 전달합니다.
- **웹소설·드라마**: 선택 글의 아이디어를 RP 설정·전개로 채택하도록 안내합니다. 캐릭터가 팬 게시글을 읽거나 배우가 되는 설정은 추가하지 않습니다.

선택 자료는 일반 RP 생성 요청의 `generationGuide`에 첨부됩니다. 실제 사용자 메시지를 수정하지 않습니다. 전송 상태와 호스트의 프롬프트 보기에서 첨부 여부를 확인할 수 있습니다. 모델의 실제 반영을 보장하지는 않습니다.

최근 10분 소재 자동 선택은 세계 주민 관점에서 RP 시간 연동이 켜져 있을 때만 동작합니다. 직접 선택한 글은 자동 선택 설정과 별도로 전달됩니다. 직접 정한 관점에는 소재 전달을 적용하지 않습니다.

## 로어북과 LTM

세계 주민 관점에서는 선택한 글·댓글과 관련 RP 경과를 요약해 연결된 로어북에 저장하거나 갱신할 수 있습니다. 요약 전용 지침과 직접 추가하는 키워드를 지원합니다. 자동 키워드는 구체적인 사건 구절을 고르도록 제한합니다.

LTM 참고는 호스트의 `long-term-memory/search` 기능과 해당 에이전트·인증이 필요합니다. 현재 RP 및 공용 기억을 최대 6개·1,200토큰 범위로 검색하며 관련 본문을 최대 4,800자까지 사용합니다. 기존 호스트 인증값을 요청 시 전달하고 별도 복사본을 설정에 저장하지 않습니다. 검색 실패는 화면에 표시하며 게시글 생성은 계속할 수 있습니다.

## 화면·저장·성능

다크모드, 제목·닉네임 볼드체, 모바일 입력칸 16px, 다섯 메뉴 한 줄 배치를 지원합니다. 큰 기록은 네이티브 gzip으로 무손실 압축하며 저장 오류·재시도·전체 백업을 제공합니다.

화면 전체 변경 감시, 주기적인 방 확인, 외부 글꼴 다운로드, 스크롤 애니메이션을 사용하지 않습니다. 테마를 복원하면서 해당 처리를 다시 추가하지 않았습니다. 다만 발열과 생성 시간은 기기·호스트·모델·선택한 참고 자료의 양에 따라 달라집니다.
